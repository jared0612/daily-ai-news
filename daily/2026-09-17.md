## 📄 研究论文

- **Giving Candidates Their Own Screening Agent Raised Borderline Pass Rates From 4.5% to 26.2%** 📅 2026-09-17 | arXiv:2609.19530
  作者/机构：多机构合作研究
  核心贡献：提出候选人与招聘方双侧 Agent 交换机制，将简历筛选从单向评估升级为双向证据交换。实验覆盖 600 个构造简历-职位匹配对，在边界池中通过率从 4.5% 跃升至 26.2%（GPT-5.5）和 6.5% 升至 16.1%（Claude Opus 4.7）。同时验证了双侧 Agent 机制并非简单放宽标准，而是通过更全面的证据交换实现更精准的筛选决策。
  摘要：传统单轮简历筛选依赖招聘方视角，容易遗漏候选人真实潜力。本研究设计了候选人和招聘方各持一个 Agent 进行证据交换的双 Agent 框架，在 191 对边界样本中效果显著，表明 Agent 间协作式信息交换可有效降低误判率。该框架对构建公平、高效的 AI 招聘系统具有直接参考价值，也为多 Agent 协作评估范式提供了新的实验证据。
  链接：[arXiv](https://arxiv.org/abs/2609.19530)

- **Reasoning Made GUI Agents More Resistant to Default Nudges and More Vulnerable to Social Ones** 📅 2026-09-17 | arXiv:2609.19843
  作者/机构：多机构合作研究
  核心贡献：对 6 个前沿模型共 3,600 个 GUI Agent 开展随机化实验，覆盖 21,600 次模拟购物场景，系统验证推理能力配置对界面诱导操作的抵御效果。发现延伸推理可降低对自动默认诱导的敏感性，但同时提升了对社交型诱导操作的脆弱性——推理能力的增强并非带来全面鲁棒性，而是将操控风险从一类转移到另一类。
  摘要：GUI Agent 已被广泛部署于自动化办公和业务流程，但其在面对用户界面中各类诱导设计时的行为脆弱性尚缺乏系统研究。本论文通过大规摸实验揭示了一个重要悖论：赋予 Agent 更强的推理能力，并不必然提升其整体安全性，反而可能重塑攻击面。实验表明自动型诱导（如默认选项预选）在强推理配置下更难生效，而社交型诱导（如虚假紧迫感提示）在强推理配置下更易被接受。这一发现对 Agent 安全评估框架的设计具有重要警示意义。
  链接：[arXiv](https://arxiv.org/abs/2609.19843)

- **Multi-Agent Collaboration Pays Only on Long-Horizon Tasks With Sparse Dependencies** 📅 2026-09-17 | arXiv:2609.19759
  作者/机构：多机构合作研究
  核心贡献：系统绘制多 Agent 协作优于单 Agent 的能力边界，发现收益完全由任务结构决定而非模型强度。协作红利集中于长时域、稀疏依赖任务；紧密耦合的顺序工作流反而因协作开销带来纯负收益。研究同步提出 SAIGE 机制（按需生成协作图），并给出对实践者最有价值的负面结论：扩大 Agent 池或加深递归深度并不能可靠改善结果。
  摘要：多 Agent 系统已成为当前 AI 应用的主流架构范式，但关于其适用边界的研究仍不充分。本论文通过系统实验证明，多 Agent 协作的优势严格受限于任务的时间跨度和依赖结构。在需要跨长时域积累证据且步骤间依赖稀疏的场景（如研究助理、多步骤代码审查），多 Agent 协作可带来显著收益；但在紧密顺序依赖的工作流中（如单函数实现），协作成本完全成为纯开销。SAIGE 机制通过内容检索动态构建协作图，验证了按需生成策略的有效性，同时确认了 Agent 池规模与任务效果之间不存在简单正相关关系。
  链接：[arXiv](https://arxiv.org/abs/2609.19759)
