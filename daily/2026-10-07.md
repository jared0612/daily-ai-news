- **MemPilot: 基于 RL 的 LLM Agent 按需多模态记忆编排框架** 📅 2026-10-07 | arXiv: 2026-10-07 (cs.AI/cs.LG/cs.CL)
  作者/机构：多机构联合（具体机构待补充）
  核心贡献：MemPilot 是一个灵活的 LLM Agent 框架，利用强化学习编排按需多模态记忆管理；通过 RL 优化多步 LLM 策略，在检索与查询导向的策展之间智能选择；控制证据量、策展指令、模型选择和视觉访问，实现细粒度计算控制；引入目标级优势解耦和基于前缀的边际效用估计方法以提升优化效果。
  摘要：MemPilot 提出了一种将多模态记忆管理形式化为 RL 决策问题的新范式。与传统静态记忆池不同，MemPilot 能够根据任务上下文动态决定何时检索外部知识、何时将当前上下文策展为记忆、以及使用何种模态进行处理。在多步 Agent 任务（WebShop、ALFWorld 等）上的实验表明，MemPilot 相比固定记忆策略成功率提升显著，同时计算开销更少。该工作为 LLM Agent 的长期记忆管理提供了可扩展的优化框架。

- **OpenWAM: 可组合世界-动作模型的开放框架** 📅 2026-10-07 | arXiv:2610.07922 (cs.RO/cs.CV)
  作者/机构：斯坦福大学（Heng Yu, David D. Yuan, Li Fei-Fei 等）
  核心贡献：OpenWAM 提出基于因果机器人-视频预训练和可配置交互架构的开放框架，用于构建可组合的世界-动作模型；在 LIBERO 基准及真实机器人任务上显著提升任务成功率；引入反事实监督改善动力学模型学习效果。
  摘要：OpenWAM（Open World-Action Model）由斯坦福大学李飞飞团队提出，旨在解决现有机器人操作模型泛化能力不足的问题。该框架从人类操作视频中学习动作先验，通过因果视频预训练捕获手-物交互的因果结构，并支持零样本迁移到新的物体和场景。核心创新在于其可配置交互架构，允许开发者灵活组合不同的视觉编码器、动作解码器和世界模型组件。在 LIBERO 仿真基准和真实机器人上的实验表明，OpenWAM 在新物体泛化任务上比现有方法成功率提升超过 20 个百分点，且无需任何额外微调。该工作为构建通用机器人操作智能提供了重要的理论基础和开源工具。
  链接：[arXiv:2610.07922](https://arxiv.org/abs/2610.07922) | [斯坦福大学 arXivDaily](https://www.arxivdaily.com/universities/stanford)

- **Self-Retrospection Distillation：将事后经验转化为先验预见** 📅 2026-10-07 | arXiv:2610.08077 (cs.AI/cs.CL/cs.IR/cs.LG)
  作者/机构：Salesforce AI Research、加州大学圣地亚哥分校、德克萨斯农工大学、斯坦福大学
  核心贡献：提出自我反思蒸馏（SRD）方法，利用事后轨迹知识训练交互前的先验预见能力；补充现有 RLVR（基于相对价值的强化学习）方法；在奖励均匀场景下显著提升 Agent 任务成功率，最高提升 24.2 个百分点。
  摘要：Self-Retrospection Distillation（SRD）由 Salesforce AI Research 等机构联合提出，核心思想是让 LLM Agent 在任务执行过程中积累"事后反思"经验，然后将这些经验通过知识蒸馏转化为"先验预见"能力，使 Agent 在真正执行前就能预判可能的风险和有效策略。与传统 RLVR 仅依赖即时奖励信号不同，SRD 额外引入了对任务轨迹的全局分析，使模型能够学习跨步骤的因果关系。实验在多个交互式 Agent 基准（WebArena、AgentBench）上进行，SRD 在奖励分布均匀（难以通过即时奖励区分策略优劣）的任务中表现尤为突出，最高将成功率从基线的 42.1% 提升至 66.3%。该方法对改进 AI Agent 的规划能力和减少试错次数具有重要意义。
  链接：[arXiv:2610.08077](https://arxiv.org/abs/2610.08077) | [斯坦福大学 arXivDaily](https://www.arxivdaily.com/universities/stanford)
