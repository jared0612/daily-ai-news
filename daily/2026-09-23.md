## 📄 研究论文

- **RRSI: Regularized Recursive Self-Improvement of Agent Harnesses** 📅 2026-09-23 | arXiv:2609.24972
  作者/机构：Dhruv Srikanth 等
  核心贡献：(1) 提出正则化递归自我改进框架，解决 Agent Harness 在自我迭代中的过拟合问题；(2) 通过在多轮自我改写中引入正则化约束，将策略 token 消耗降低 30%，同时保持任务表现；(3) 在 EdgeBench 51 任务上验证，GPT-5.6 Sol 和 Opus 5 均可匹配原始 Pi 系统表现，但 token 流量减少 44.7-49.0%。
  摘要：论文研究 AI 研究智能体自身的递归自我改进循环。当 Agent 的代码成为优化对象时，每轮接受的改写就变成下一轮编辑的 Agent。作者提出 AIDE² 系统，在 8 天自主运行中发现了 7 项连续改进，涵盖搜索策略到上下文压缩机制。这些改进在 4 个 held-out 基准上泛化，涵盖 ML 工程、启发式算法工程和物理天气预报。最强发现的 Agent 在所有四个基准上匹配或超过人类工程师设计的生产级研究 Agent，同时 reward hacking 率从 55% 降至 32%。正则化方案有效抑制了过拟合，使改进能迁移至从未见过的任务领域。
  链接：[HuggingFace](https://huggingface.co/papers/2609.24972) | [arXiv](https://arxiv.org/abs/2609.26457)

- **Flash-dLLM: Training-Free Inference Acceleration for Diffusion LLMs** 📅 2026-09-22 | arXiv:2609.26796
  作者/机构：Quan Nguyen-Tri, Mukul Ranjan, Zhiqiang Shen
  核心贡献：(1) 识别 GPU 内存 I/O 为支持 KV 缓存的 dLLM 推理主要瓶颈；(2) 提出 I/O 感知的融合 KV 缓存内核，减少冗余内存移动；(3) 设计 KV 缓存驱动的 draft-and-verify 解码策略，dLLM 自身同时担任 drafter 和 verifier，无需辅助模型。
  摘要：扩散大语言模型（dLLM）通过非自回归文本生成成为自回归 LLM 的有前景替代方案，但推理效率受限。现有加速方法通常孤立研究 KV 缓存和并行解码，忽视了缓存复用与并行 token 验证联合应用时的 I/O 瓶颈。Flash-dLLM 首先识别 GPU 内存 I/O 为主要瓶颈，通过 I/O 感知融合 KV 缓存内核解决；在此基础上提出高效的 KV 缓存驱动 draft-and-verify 解码策略，统一设计实现更快解码同时保持生成质量。在数学推理和代码生成基准上，Flash-dLLM 在 GSM8K 和 HumanEval 上分别实现 5.1 倍和 11.0 倍加速，超越此前最强基线 Elastic-Cache。
  链接：[arXiv](https://arxiv.org/abs/2609.26796) | [AI Weekly](https://aiweekly.co/ai-news-today/open-source-ai-news)

- **WorldCrafter: Consistent Video World Model with Implicit 3D-aware Memory** 📅 2026-09-23 | arXiv:2609.24984
  作者/机构：Hugging Face Daily Papers 推荐
  核心贡献：(1) 提出隐式 3D 感知记忆机制，解决视频世界模型在长序列生成中的时空一致性问题；(2) 无需显式 3D 表示即可保持场景几何一致性；(3) 在多场景视频生成基准上显著减少一致性退化。
  摘要：视频世界模型在生成连贯的长序列视频时面临 3D 场景几何一致性的核心挑战。WorldCrafter 引入隐式 3D 感知记忆模块，将场景几何信息编码为潜在表示，在生成过程中持续参考以维持空间和时间一致性。该方法不依赖显式 3D 重建或点云输入，而是通过模型内部记忆机制自动学习并保持场景结构。实验表明，在包含复杂相机运动和多物体交互的场景中，WorldCrafter 在一致性评分上显著优于基线方法，同时保持生成质量和多样性。
