## 📄 研究论文

- **Hunyuan-A13B Technical Report** 📅 2026-09-23 | arXiv:2609.27284
  作者/机构：腾讯混元团队（Tencent Hunyuan Team，含 Ao Liu、Botong Zhou、Can Xu 等）
  核心贡献：（1）提出 80B 总参数 / 13B 激活参数的 MoE 开源模型，兼顾推理成本与能力；（2）采用双模式思维链（dual-mode CoT），可按任务复杂度自适应调整推理深度，实现「快思考 / 慢思考」切换；（3）在数学、科学、代码与通用推理基准上取得与同级别模型可比的表现，进一步扩展了 sub-15B 激活参数这一档开放权重的竞争格局。
  摘要：该技术报告系统介绍了腾讯混元 A13B 的架构设计与训练流程，核心是总参数量约 800 亿、单次前向仅激活约 130 亿参数的混合专家（MoE）结构，配合双模式 Chain-of-Thought 机制，使模型在面对简单问题时走短路径、面对复杂问题时自动进入更深层推理。报告指出该模型在数学、科学、代码与通用推理等多类任务上具备竞争力，同时保持了较低的单位推理成本，与近期闭源模型普遍呈现的 fast/slow-thinking 模式相互呼应。作为又一款可信的开放权重 MoE，它为开发者提供了 15B 激活参数以下档位的开源替代方案。
  链接：[arXiv](https://arxiv.org/abs/2609.27284) | [PDF](https://arxiv.org/pdf/2609.27284)

- **Memory Attention：用 token 索引记忆替代密集 value 投影** 📅 2026-09-23 | arXiv:2609.28399
  作者/机构：Jiale Kang（个人研究）
  核心贡献：（1）提出 Memory Attention（MA）机制，将注意力中的 value 构造改为「层级 token 记忆 + 上下文 key」的组合；（2）推理时可将归一化折叠进记忆表，把 value 构造简化为查表与加法；（3）token 索引式检索支持 CPU 卸载与预取，降低 GPU 参数存储占用。
  摘要：语言模型通常从上下文隐状态构造注意力 value，即便其中部分内容是可跨上下文复用的。本文研究「token 索引记忆」能否在上下文信息补充下取代专门的 value 投影。作者提出的 Memory Attention 通过将层级专属的 token 记忆与上下文 key 相结合来构造 value：记忆提供 token 专属表征，key 保留上下文依赖。推理阶段，归一化可以折叠进记忆表，使 value 构造退化为查表加加法；token 索引式检索还支持带预取的 CPU 卸载，从而减少 GPU 上的参数存储。在匹配训练 token 预算并增加记忆参数的情况下，多种注意力配置的实验均显示出更好的语言建模效果与平均下游表现。该工作针对的是 Transformer 注意力内部的基础计算成本，而非仅依赖量化或服务层优化。
  链接：[arXiv](https://arxiv.org/abs/2609.28399) | [HTML](https://arxiv.org/html/2609.28399v1)

- **Log-Depth Recurrent Language Modeling：对数深度循环语言模型** 📅 2026-09-23 | arXiv:2609.28212
  作者/机构：Yiqin Wang、Nuri Cingillioglu、Charles Pert
  核心贡献：（1）将序列编码中的平衡树递归算子推广到自回归预测；（2）使所有前缀表征可用对数深度、线性运行时间计算；（3）实验显示稳健的长度外推能力与接近 ALiBi Transformer 的性能。
  摘要：基于 Transformer 的语言建模虽已成主流，但其计算深度固定、运行时间随输入 token 二次增长；循环模型虽然深度线性，却无法并行执行。本文把此前用于序列编码的平衡树递归算子扩展到自回归预测，使所有前缀表征都能以对数计算深度、线性运行时间完成计算。作者对该模型类做了初步刻画，实验表明其具备稳健的长度外推能力，性能逼近基于 ALiBi 的 Transformer，展现出作为语言建模替代架构的潜力。该工作位列「超越标准 Transformer 缩放」这一研究浪潮之中，对开放模型生态具有长期意义：推理效率正越来越取决于架构设计，而非仅仅是更小的参数量或更激进的量化。
  链接：[arXiv](https://arxiv.org/abs/2609.28212) | [PDF](https://arxiv.org/pdf/2609.28212)

- **Towards Efficient Reasoning: Learning Causal Shortcuts for Diffusion Language Models** 📅 2026-09-23 | arXiv:2609.28272
  作者/机构：Dian Jin、Kairong Han、Baohong Li、Xinpeng Dong 等（浙江大学）
  核心贡献：（1）提出「因果捷径」（causal shortcuts）概念，即覆盖全序列并显式引导正确推理轨迹的 token 链；（2）提出因果捷径学习（CSL）框架，含逐步 token 抽取与并行优先掩码训练；（3）在多个推理基准与两个基座模型上平均提升 1.92%，MATH-500 上最高提升 4.20%。
  摘要：扩散语言模型（DLM）因其强推理能力备受关注，但在双向注意力机制下，其探索空间相比自回归模型呈指数级膨胀，导致在随机掩码下难以聚焦到引导推理的 token。作者将「因果捷径」定义为覆盖整条序列、能为正确推理轨迹提供显式引导的 token 链，并分析了因果捷径对 DLM 推理准确率与收敛速度的影响，发现其能大幅提升答案收敛效率与生成准确率。据此提出 CSL 框架：先通过逐步 token 抽取过程从数据中提取因果捷径，再在训练时对这些 token 施加并行优先掩码，从而经由因果捷径高效且准确地收敛到正确答案。在多个推理基准与两个基座模型上的实验显示，CSL 持续优于现有 SFT 变体基线，相比纯 SFT 平均提升 1.92%，在 MATH-500 上最高提升 4.20%。代码已开源。
  链接：[arXiv](https://arxiv.org/abs/2609.28272) | [GitHub](https://github.com/ZJUDianJin/Causal-Shortcuts-Learning)
