## 📄 研究论文

- **[APIFlow-Bench: Measuring Whether Agents Survive Long, Dependent API Workflows]** 📅 2026-09-01 | arXiv:2608.29128
  作者/机构：Postman Inc. & 多所高校联合团队
  核心贡献：推出 APIFlow-Bench 基准，评估 AI 智能体完成长时程、存在依赖关系的 API 工作流的能力，覆盖 44,362 条执行记录，发现依赖链长度与模型可靠性是成功率的核心制约因素，且复合故障不符合独立误差假设。
  摘要：本文针对 AI Agent 在真实 API 生态中的可靠性问题，提出首个系统性评估框架。研究定义了"长时程依赖工作流"任务类型，构建了包含多步骤、跨服务依赖的真实 API 调用场景数据集。实验发现当前模型在依赖链深度超过 5 层时成功率急剧下降，且多步骤故障的累积效应显著强于单步误差的线性叠加，表明现有 Agent 框架对复合故障的处理能力严重不足。该基准为 API Agent 的生产部署提供了可量化的可靠性参考标准。
  链接：[arXiv](https://arxiv.org/abs/2608.29128) | [GitHub](https://github.com/postmanlabs/APIFlow-Bench)

- **[Wrong Prediction, Right Answer: Recovering Evidence from Collapsed LLM Sequence Scores]** 📅 2026-09-01 | arXiv:2608.31068
  作者/机构：北京大学、艺心 AI 实验室、北京人工智能研究院
  核心贡献：发现大语言模型推理失败多为"表达缺陷而非逻辑缺失"，提出无需目标标签的加性校正方法，可恢复 Qwen 等模型的推理准确率，为基准评估提供更严谨解读，填补了模型可解释性领域的重要空白。
  摘要：本研究发现，当前主流 LLM 在复杂推理任务中的失败，并非源于真正的逻辑推理缺陷，而更多是表达层面的失败——模型"知道"正确答案，但在序列化输出过程中发生了标记选择错误。研究者在三个受控逻辑推理数据集（ProofWriter、ANLI、FOLIO）上对 Qwen3.5、OLMo-2-1B、Llama-3.1-8B 等模型进行系统评估，发现约 37% 的"错误回答"实际上包含了正确答案的证据，只是被错误标记序列所掩盖。基于此发现，研究团队提出了无需人工标注的加性校正（Additive Calibration）方法，通过分析模型序列得分分布来恢复潜在正确答案，无需额外训练或标注数据即可提升评测准确性。该工作对理解 LLM 能力边界和设计更可靠的基准评测体系具有重要意义。
  链接：[arXiv](https://arxiv.org/abs/2608.31068) | [北京大学arXivDaily](https://www.arxivdaily.com/universities/peking?page=1&submission=new)

- **[SUN: Persistent Programs For Language-Grounded Control-to-Learning-to-Real Policies]** 📅 2026-09-01 | arXiv:2608.31167
  作者/机构：UCLA、UCSB、Amazon、机器人与 AI 研究院
  核心贡献：提出语义统一（SUN）持久程序框架及 Kuafu 系统，由大型视觉-语言系统自动合成控制策略，在 9 项任务中实现 82.03% 宏观成功率，显著优于相关基准，首次实现符号规划与数据驱动执行的统一。
  摘要：本论文针对机器人控制中"模型预测控制"与"学习策略"之间的语义断层问题，提出了一种将语言指定目标直接转化为持久控制策略的新方法。SUN 框架的核心创新在于将控制执行从手工设计奖励函数中解放出来，转而依赖自然语言指令作为语义锚点。研究团队构建了 Kuafu 系统，在 9 个不同复杂度级别的操控与导航任务中进行评估，包括物体抓取、场景重排、动态避障等，结果显示 SUN 在宏观成功率上比现有最优方法提升超过 15 个百分点。该工作为"语言驱动的机器人控制"提供了一条可验证、可复现的技术路径。
  链接：[arXiv](https://arxiv.org/abs/2608.31167) | [arXivDaily](https://www.arxivdaily.com/)

- **[MNIST-PRO: MNIST is Back as a Partially Observable World for AI Agents]** 📅 2026-09-01 | arXiv:2608.31022
  作者/机构：南洋理工大学（NTU）、ASTAR（新加坡科技研究局）
  核心贡献：将经典 MNIST 数字识别任务改造为部分可观测的顺序搜索环境（MNIST-PRO），系统评估多模态 AI Agent 在不确定性下的感知整合、探索持续性与信念修正三大核心能力，发现当前主流模型均存在显著瓶颈。
  摘要：本研究指出，当前 Agent 评估基准往往假设完整信息，而现实场景中 Agent 必须基于不完整信息进行推理和决策。为填补这一评估空白，研究团队将 MNIST 数据集重新设计为具有回溯约束的顺序搜索任务：Agent 需在有限视野内主动探索数字像素分布，推断当前所见的具体数字，并在累积证据不足时动态修正信念。实验覆盖 GPT-4V、Claude、Gemini 等主流多模态模型，结果揭示了三大共性瓶颈：感知整合不连贯（多帧信息难以融合）、探索策略浅尝辄止（过早做出判断）以及信念修正机制缺失（初始误判后无法有效纠错）。该基准为零样本多模态 Agent 评估提供了低成本、高可复现性的测试床。
  链接：[arXiv](https://arxiv.org/abs/2608.31022) | [NTU arXivDaily](https://www.arxivdaily.com/universities/ntu-singapore?page=1&submission=new)

- **[Sliding-Window Beats Linear Attention: 无需训练的滑动窗口注意力超越专用线性注意力]** 📅 2026-09-01 | arXiv:2608.28444
  作者/机构：Microsoft Applied Sciences Group
  核心贡献：发现在长上下文推理任务中，无需任何额外训练的滑动窗口注意力（SWA）配合注意力汇聚点即可达到甚至超越经过专门后训练的线性注意力模型，同时解码吞吐量更高、KV Cache 显存成本固定。
  摘要：本文挑战了"长上下文 LLM 推理必须使用线性注意力或稀疏注意力"的行业共识。通过在多种长上下文基准（S-NIAH、BABILong 等）上的系统性实验，研究者发现，带注意力汇聚点的滑动窗口注意力（SWA）不仅能在短任务上平均恢复全注意力模型约 99% 的性能，还能在长上下文任务中以 2-10 倍的优势超越线性注意力方案。更关键的是，SWA 的 KV Cache 大小在窗口填满后不再随上下文长度增长，实现了固定显存占用。该发现对当前大模型推理优化具有直接的工程价值。
  链接：[arXiv](https://arxiv.org/abs/2608.28444) | [腾讯新闻论文速递](https://news.qq.com/rain/a/20260901A0CEQ700)
