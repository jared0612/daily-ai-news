## 📄 研究论文

- **Transformers v5.17.0: 新增七种架构、HYV4/GLM-5.3-Flash/Kimi Linear 支持** 📅 2026-09-09
  作者/机构：Hugging Face 团队
  核心贡献：新增腾讯 780B MoE 模型 HYV4（49B 激活参数、100 万上下文）、Moonshot AI 的 Kimi Linear 线性注意力架构；统一 Vision RoPE 改进 2D/3D 视觉模型；新增 VibeVoice（多说话人语音合成）、NeoMME 多模态编码器、Fun-ASR-Nano 等架构。Diffusers 0.40.0 同步新增 MiniMax-H3（视频+音频联合生成）、Stable Audio 3、Wan-Animate-2 等 pipeline。
  摘要：Transformers v5.17.0 是该库历史上最大规模架构扩展之一，一次性引入七种全新模型架构，涵盖 MoE、线性注意力、多模态语音等前沿方向。HYV4 采用 Multi-head Latent Attention（MLA）压缩 KV 缓存，结合 DeepSeek Sparse Attention（DSA）实现高效稀疏路由，总参数量 780B、激活 49B，上下文窗口达 100 万 token，超越大多数开源模型。Kimi Linear 则以 Gated DeltaNet 为核心变体，为长上下文任务提供线性复杂度的注意力替代方案。VibeVoice 引入「next-token diffusion」机制，在 LLM 结构内实现高质量长语音生成，特别适合播客和有声书场景。此次更新同时改进了量化、缓存和 kernel 性能，为 2026 年下半年 Agent 应用爆发提供底层支撑。链接：[Hugging Face Release Notes](https://releasebot.io/updates/huggingface) | [Transformers v5.17.0](https://releases.sh/hugging-face) | [ThursdAI](https://thursdai.news/releases/2026-09)

- **TRL v1.13.0: 支持百万 token 训练、PPOTrainer 移除** 📅 2026-09-10
  作者/机构：Hugging Face TRL 团队
  核心贡献：首次在单台 8×H100 节点上完成 1,048,576 token/步的训练实验；chunked cross-entropy projection 改为张量核计算，端到端加速 1.69 倍；PPOTrainer 作为库中最老 trainer 被正式删除；DistillationTrainer 从 experimental 毕业为正式模块。
  摘要：TRL v1.13.0 将大规模上下文训练从研究探索推向工程可行。1M token 训练窗口意味着 Agent 系统现在可以在单次前向传播中「看到」整本长文档或完整代码库，极大提升多跳推理和长程规划能力。chunked cross-entropy 的张量核化是推理侧的关键工程改进——此前 chunked 方式的优势被 CPU-GPU 数据搬运所抵消，新实现在张量核上直接完成投影，1.69 倍端到端加速对生产部署意义重大。PPOTrainer 的移除标志着 RLHF 管线向更精简架构的统一演进。vLLM-serve 的集成也进一步简化了推理服务的工程复杂度。链接：[AI/TLDR](https://ai-tldr.dev) | [ThursdAI](https://thursdai.news/releases/2026-09)

- **DeepSeek V4.1 Flash: 552B MoE 模型，KV 缓存压缩 400 倍** 📅 2026-09-10
  作者/机构：DeepSeek AI
  核心贡献：总参数 552B，prefill 阶段仅激活 8B，decode 激活 16B；原生多模态视觉；100 万 token 上下文；KV 缓存从每 token 389,000 字节压缩至 890 字节（>400 倍）；MIT 许可证。
  摘要：DeepSeek V4.1 Flash 的核心突破在于 KV 缓存的极端压缩——890 字节/token 意味着在固定内存池内可容纳的 Agent 会话长度提升三个数量级，使得「一个会话完成整个项目」成为可能。45 万亿多模态 token 训练（文本+图像）保证了视觉理解的基座能力。DeepSeek 自评 Terminal-Bench 2.1 得分 90.6（V4-Pro: 85.3），DeepSWE 1.1 得分 74.2，高于 Opus 5 和 GPT-5.6 Sol，每任务成本约 2 美分，展现了稀疏 MoE 在成本-性能帕累托前沿上的统治力。链接：[DeepSeek on Hugging Face](https://huggingface.co/deepseek-ai/DeepSeek-V4.1-Flash) | [AI Briefing](https://myaiguide.co/news/daily-roundup-20260907)
