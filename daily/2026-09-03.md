## 📄 研究论文

- **SafeEvolve: Harness-Policy Co-Evolution from Agent Experience for Safety Alignment** 📅 2026-09-03 | arXiv:2609.02786
  作者：华中科技大学、清华大学等多机构联合
  核心贡献：提出 SafeEvolve 框架，通过"安全策略协同进化"机制让 Agent 在真实任务执行中持续学习安全规则，同时提升任务成功率和安全合规率。该方法在多个 benchmark 上显著优于传统 post-hoc 安全对齐方案。
  摘要：本文探索了如何让 AI Agent 在与环境交互过程中自动发现并纠正安全策略漏洞。研究团队设计了一个双层进化结构：底层是任务策略（Task Policy），负责完成用户目标；上层是安全策略（Harness Policy），负责监控并约束底层行为。两层通过强化学习协同进化，在模拟器与真实任务数据上验证了方法的有效性，展示了"边做边学安全"的可行路径，对未来高自主性 Agent 的安全训练具有重要参考价值。
  链接：[arXiv](https://arxiv.org/abs/2609.02786)

- **Discriminative World Models for Web Agents** 📅 2026-09-03 | arXiv:2609.02885
  作者：Kelvin Li、Dhruv Pendharkar、Leonid Karlinsky、Trevor Darrell 等（MIT/Google/Berkeley 联合团队）
  核心贡献：提出专为 Web Agent 设计的判别式世界模型（Discriminative World Model），区别于传统生成式世界模型，该方法直接对"状态转移是否正确"进行判别式建模，大幅降低 Web 导航任务的计算开销，同时提升了长程任务中的状态跟踪精度。
  摘要：Web Agent 需要在动态 HTML 页面流中执行多步操作，现有方法依赖昂贵的生成式世界模型进行状态预测。本文提出用判别式方法替代生成式：给定当前页面状态与候选操作，模型直接预测操作结果是否达成目标，而不生成完整页面快照。实验表明，该方法在 WebArena、WebShop 等基准上将推理速度提升 3-5 倍，同时任务完成率与生成式基线持平或更高，对构建高效浏览器 Agent 具有直接实用价值。
  链接：[arXiv](https://arxiv.org/abs/2609.02885)

- **Post-Training Language Models for Gold-Medal Performance in Coding Competitions** 📅 2026-09-03 | arXiv:2609.02849
  作者：Aleksander Ficek、Sean Narenthiran、Mehrzad Samadi、Boris Ginsburg（NVIDIA 研究团队）
  核心贡献：系统研究编程竞赛后训练（Post-Training）策略，探索了数据配比、训练范式和评估方法对模型在竞赛编程中夺金能力的影响，提供了目前最完整的 Code-LLM 竞赛调优经验报告。
  摘要：本文深入研究了如何将通用 LLM 调优至具备国际信息学奥林匹克（IOI）金牌选手级别的编程能力。研究团队系统对比了多种后训练方案，包括：竞赛代码数据筛选与质量评分、多轮强化学习（PPO/DPO）调优、代码执行反馈驱动的微调等。实验发现，单纯扩大训练数据规模效果有限，关键在于数据质量（去重、难度分级、反馈信号注入）和训练范式（结合执行结果的后训练显著优于纯 SFT）。最终模型在多个编程竞赛基准上达到或超越人类金牌选手水平，对 Code Agent 的实用化部署有重要指导意义。
  链接：[arXiv](https://arxiv.org/abs/2609.02849)
