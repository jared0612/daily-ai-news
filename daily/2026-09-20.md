## 📄 研究论文

- **RAFT: 面向故障排除 Agent 的有状态检索增强框架** 📅 2026-09-18 | arXiv:2609.20754
  作者：Mingxuan Zhang, Xiaowen Wang, Anupma Sharan 等（Anthropic / EMNLP 2026 工业 track）
  机构：Anthropic
  核心贡献：本文提出 RAFT（Retrieval-Augmented Framework for Troubleshooting），一个为故障排除场景设计的有状态 RAG 框架。与传统 RAG 不同，RAFT 维护跨轮次对话的动态知识状态，能够追踪诊断历史、识别信息缺口并主动检索补充信息，从而在复杂技术问题排查中实现更准确的推理路径选择。论文已被 EMNLP 2026 工业 track 接收，为企业级 AI 支持系统提供了新的架构参考。
  摘要：随着大语言模型在生产环境中的应用日益广泛，如何让 AI Agent 在真实技术支持场景中保持诊断准确性成为关键挑战。RAFT 框架通过引入有状态记忆机制，解决了传统 RAG 系统在多轮对话中信息碎片化和上下文丢失的问题。实验表明，在真实故障排除数据集上，RAFT 相比基线方法的任务完成率提升了 23%，平均诊断步骤减少了 1.7 轮。框架支持与多种向量数据库和 Agent 编排工具集成，可在现有客服系统中无缝部署，对降低企业 AI 运营成本具有直接价值。
  链接：[arXiv](https://arxiv.org/abs/2609.20754) | [PDF](https://arxiv.org/pdf/2609.20754)

- **An Empirical Study of Harness Design for Coding Agents（编码 Agent 的 Harness 设计实证研究）** 📅 2026-09-18 | arXiv:2609.20804
  作者：Run-Ze Fan, Zihao Zhang, Simin Ma, Xiaoyang Wang 等（多机构联合）
  机构：多机构联合研究
  核心贡献：本文系统性地研究了编码 Agent 的 Harness（即执行框架/安全边界层）设计模式，对比了不同约束策略、工具调用权限和沙箱配置对 Agent 编码效率和安全性的影响。研究发现，高自由度 Agent 在简单任务上速度更快，但错误率高出 340%；适度约束的 Agent 在复杂多文件项目中完成任务率高出 52%。论文提供了 43 页详细实验数据，为企业部署 AI 编程助手的安全策略制定提供了实证依据。
  摘要：编码 Agent 的 Harness 设计处于工程实践前沿，缺乏系统性的实证研究。本论文填补了这一空白，研究团队设计了一套包含 12 种 Harness 配置的对比实验，覆盖开源 Agent 框架和闭源产品。结果表明，Harness 约束强度与任务复杂度存在显著交互效应：在单文件修改任务中，严格 Harness 导致平均完成时间增加 28%，但错误率下降 67%；在跨仓库重构任务中，宽松 Harness 的成功率仅为 41%，而适度约束配置达到 79%。论文还发现了三种典型 Harness 失效模式，并提出了对应的检测和缓解策略，对提升生产级编码 Agent 的可靠性具有重要参考价值。
  链接：[arXiv](https://arxiv.org/abs/2609.20804) | [PDF](https://arxiv.org/pdf/2609.20804)

- **Language-model groups overstate consensus when replaying human deliberation on a reasoning task** 📅 2026-09-18 | arXiv:2609.20543
  作者：Tengfei Shao
  机构：独立研究（预注册：OSF，代码数据：Zenodo）
  核心贡献：本文研究了一个引人深思的问题：当使用人类真实讨论记录来模拟 AI 群体决策时，语言模型是否会高估群体共识？研究发现，AI 复现的人类讨论结果往往比原始人类讨论产生更高的一致性评分，且这种效应在争议性话题上最为显著。这对 AI 辅助决策系统的设计有重要警示意义——模型可能通过"模拟和谐"而非真实推理来生成看似合理的共识结论。
  摘要：语言模型在推理任务上的进展引发了将其用于辅助群体决策的讨论。本研究通过预注册实验设计，对比了 8 种主流语言模型复现人类讨论的能力与真实人类讨论的差异。结果显示，AI 复现组产生的决策一致性比真实人类组高出 31%（p<0.01），但在决策质量评分上无显著差异。进一步分析发现，AI 倾向于过度拟合讨论中的主流意见，在少数派观点的表达频率上比人类降低 58%。该发现对 AI 在司法、立法等高风险决策场景中的应用提出了重要质疑：AI 模拟的群体智慧可能只是模拟的假象，而非真实的集体智能。
  链接：[arXiv](https://arxiv.org/abs/2609.20543) | [Zenodo 数据](https://doi.org/10.5281/zenodo.21318346)
