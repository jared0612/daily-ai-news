## 📄 研究论文

- **REMORY: 用残差记忆实现 LLM 代理上下文压缩至 5.2% 位置** 📅 2026-10-09 | arXiv:2610.11287
  作者：上海人工智能科学研究院、复旦大学、上海交大、密歇根大学、港中文、阿里、南京大学等
  核心贡献：REMORY 提出一种神经记忆网络，通过学习一组有界软记忆 token 作为冻结大语言模型的残差连接，使其在长视野任务中仅用 5.2% 的输入位置即可达到接近全上下文的表现。在 SummHay 基准上，该方法显著提升了源归因准确率并减少了工具调用错误。
  摘要：REMORY 针对 LLM Agent 会话中常驻上下文文件不断膨胀导致性能退化和成本上升的问题，创新性地引入软记忆 token 机制，在不修改冻结 LLM 参数的前提下，通过补充可学习的上下文压缩表示来维持任务性能。实验在 BrowseComp、Terminal-Bench 2.1 等长视野 Agent 基准上验证了方法有效性，代码与权重已开源至 GitHub 和 Hugging Face。
  链接：[arXiv](https://arxiv.org/abs/2610.11287) | [Hugging Face](https://huggingface.co/papers)

- **TestPrism: 超越单一参考的多实现测试评估框架** 📅 2026-10-09 | arXiv:2610.12289
  作者：Han Li 等（多机构联合）
  核心贡献：TestPrism 提出用 Joint Success Function 对 LLM 生成测试进行评估，对抗基准包含 300 个任务、3000 个候选程序，而不仅与单一参考答案比较。实验表明，14 种主流编码 Agent 配置在严格评估下仅达 28.00%，远低于单参考评估的 59.67%，揭示了当前 Agent 评测体系的系统性盲点。
  摘要：当前编码 Agent 评测依赖单一参考实现，导致"通过参考实现"不等于"正确实现"。TestPrism 引入多实现联合成功函数，强制测试代码对多种有效解和故意错误解均通过，才能判定为合格。该框架可用于更真实地评估 Agent 的代码测试能力，避免评测虚高，配套的 TestHelix 综合与同行验证方法可将严格成功率提升 8.67–9.00 分。
  链接：[arXiv](https://arxiv.org/abs/2610.12289) | [Hugging Face](https://huggingface.co/papers)

- **Memento 3: 基于反思规则书实现模型递归自我改进** 📅 2026-10-09 | arXiv:2610.11794
  作者：Haoyu Zhao、Zhengxu Yu、Zhiyuan He 等（多机构联合）
  核心贡献：Memento 3 让冻结的 LLM 持续修订外部自然语言规则书，将其编译为可执行的世界模型代码，并在语义验证和精确重放验证后才接受更新。实验表明，单一模型 Agent 在全部 25 个 ARC-AGI-3 公共游戏关卡上均达到 100% 相对人类行动效率，且仅消耗人类行动数的 44%。
  摘要：Memento 3 的核心思想是将 Agent 的经验积累从模型内部参数转移到外部结构化规则书，使同一个冻结模型能够在部分可观测环境中持续学习与自我改进，无需重新训练。该方法在长视野规划任务中表现出强大的泛化能力，为构建可持续进化的 Agent 系统提供了新范式。
  链接：[arXiv](https://arxiv.org/abs/2610.11794) | [Hugging Face](https://huggingface.co/papers)
